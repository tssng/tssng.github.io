My personal website.

To write a post (Node 22 or newer):

```sh
npm ci
npm run new:post -- "My first post"
npm run dev
```

Edit `content/posts/my-first-post/index.md` and keep its images beside it. Open the local preview, then set `draft: false` and push to `main` when ready.
